# MY SPACE Dashboard

Статично уеб приложение, готово за GitHub Pages.

## Качване

1. Създай ново repository в GitHub.
2. Качи **съдържанието** на тази папка в основната директория.
3. Отвори `Settings` → `Pages`.
4. Избери `Deploy from a branch`, branch `main` и папка `/ (root)`.

## Добавяне на постоянен линк

Отвори `links.js` и добави нов запис в `window.DASHBOARD_LINKS`, като копираш някой от съществуващите. Бутонът „Добави линк“ в самото приложение пази лични линкове само в текущия браузър.
