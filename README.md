# MY SPACE · Работен център

Централен работен център на български за Vinilpechat, FootballLeague, Audit-Hub, Caritas, НАСЛЕДСТВО AI и фитнес приложението. Обновява съществуващия dashboard; старите приложения и синхронизацията им са запазени в `legacy/index.html`, със същите ключове за браузърно съхранение и същата конфигурация.

## Навигация

Плосък списък от проекти, общ преглед, „Днес“, преглед преди публикуване и история на решенията. Търсене и филтри по проект и статус. Във всеки проект: commit-и, отворени/обединени/затворени PR-и с пагинация, workflow проверки, проблеми, задачи, бележки, решения и адреси на услугите.

PR сравненията разрешават актуалния commit на основния клон, сравняват го с точния head SHA на PR и четат workflow изпълненията за този head. Пълен diff се отваря в GitHub; големите сравнения могат да са ограничени от доставчика. Всички броячи показват обхвата на прочетените страници. Зелен build не означава преминали тестове. Данни от предишен успешен прочит остават означени като остарели при грешка.

## Данни и достъп

- Site Worker използва Sites request identity и D1. Всеки профил вижда собствените си задачи, бележки, решения и настройки. Всяка редакция е нова неизменяема версия. Старите версии могат да се възстановяват като нов запис. Историята е пагинирана и може да се експортира изцяло.
- Записите използват оптимистично заключване по номер на версия и уникален идентификатор на заявката. Конфликт връща 409 и не презаписва данните; презареди страницата преди повторна редакция.
- GitHub, Vercel и OpenSEO се четат чрез свързаните приложения на посетителя. Декларациите са само за четене; адресите и действията се избират от сървъра. Няма произволен proxy, токени в браузъра или споделени snapshots на данни от чужда връзка.
- Само за Vinilpechat са потвърдени Vercel и OpenSEO проектните идентификатори. За останалите няма измислени здравни статуси. Настройките позволяват добавяне на потвърдени адреси. За НАСЛЕДСТВО AI липсва точно хранилище/URL; таблото остава „За свързване“.
- В статичен GitHub Pages или локален преглед работните записи се пазят само в браузъра, с изрично съобщение и JSON архив. Свързаните приложения изискват Site runtime; няма скрита подмяна с примерни данни. При недостъпно D1 хранилище за удостоверен потребител записването се блокира.
- Старият Supabase режим остава само за стария изглед с връзки. Новите лични работни записи не се записват в старата споделена таблица.

## Правило за публикуване

**Няма автоматично публикуване, сливане на PR или промяна на продукцията без отделно одобрение за конкретната версия.**

Приложението няма merge/deploy/publish endpoint и няма connector права за външни записи. „Отбележи като прегледан“ е отметка за конкретния PR head SHA в текущата браузърна сесия, а не разрешение за публикуване. Контролният списък също не стартира външни действия.

Разработката се качва в отделен клон и Draft PR. Site версията се запазва без deploy до отделно одобрение. GitHub Pages production и `main` остават непроменени.

## Разработка и проверки

Node.js 22.13+; тестовете използват `node:sqlite` (проверени с Node 24).

```bash
npm ci
npm run dev
npm test
npm run build
```

`npm run dev` е само локален сървър. Не приема identity headers от браузъра. `npm run build` вгражда точно разрешените frontend файлове в `dist/server/index.js`; произволни файлове, `.git` и `.sites-runtime` не се обслужват. D1 миграциите са в `drizzle/`. Hosting настройките са в `.openai/hosting.json`.

Native connector preview е изолиран development adapter с официалния Sites mailbox runner в `scripts/connector-preview/`; той не влиза в production артефакта. Нуждае се от изрично избрани read grants и управляван агентен процес; самостоятелно `npm run dev` не дава достъп до свързаните приложения.

## Проверено при подготовка

- Backend тестове: версии, възстановяване, конфликти, повторени заявки, изолация по профил, Origin/identity проверки, небезопасни URL адреси и отказ на външни write действия.
- Локален браузър: навигация, създаване/завършване на задача, запазени предишни версии, реални GitHub прочити за петте хранилища, Vercel/OpenSEO прочити за Vinilpechat и сравнение на PR #23 с workflow резултати.
- Hosted sign-in, D1 миграция и hosted connector consent/reads остават непроверени до одобрено първо публикуване.
- Responsive CSS е подготвен за телефон; отделна реална мобилна браузърна проверка още не е извършена.

## Пълна колекция от приложения

Общият преглед включва всичките 14 приложения от постоянния списък на стария MY SPACE и първоначалните шест работни проекта: общо 19 уникални записа. BG Football и FootballLeague са един запис с общ уеб адрес и търсене по двете имена. Допълнителните приложения имат същите табла, бележки и история; свързани са само потвърдените хранилища. Приложенията с уеб адрес без намерено GitHub хранилище са обозначени „Уеб приложение“. Старият облачен списък е запазен непроменен; при проверката връщаше грешка и показваше офлайн копие с 14 приложения. Допълнителни записи само от недостъпния облак не са потвърдени.
